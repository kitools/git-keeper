# 删除git跟踪文件保留其他

## User

git有没有办法把本地目录里面属于git管理的文件都删掉，但是保留其他文件

## DeepSeek

可以使用 `git ls-files` 列出所有被 Git 跟踪的文件，然后用 `xargs` 删除它们，同时不影响未跟踪的文件（包括 `.gitignore` 中忽略的文件、新增但未 `add` 的文件等）。

### 基本命令
```bash
git ls-files -z | xargs -0 rm
```
- `-z` 和 `-0` 确保正确处理包含空格或特殊字符的文件名。
- 该命令会删除所有被 Git 版本控制的文件，但保留 `.git` 目录和所有未跟踪的文件。

### 扩展操作（可选）
删除完成后，可能会留下空目录（Git 本身不跟踪目录）。如果需要一并清理空目录（但保留 `.git` 内的目录结构），可以执行：
```bash
find . -type d -empty -not -path "./.git/*" -delete
```

### 警告
- 执行前建议先确认没有未提交的重要修改：`git status`。
- 被删除的跟踪文件**无法撤销**（除非已提交到仓库）。如果希望恢复，可以在删除后运行 `git checkout .` 或 `git reset --hard HEAD` 重新检出。
- 如果需要彻底清空工作区（包括未跟踪文件），请使用 `git clean -xdf`，这与本需求相反。

### 更安全的做法（先备份）
```bash
# 将所有跟踪文件移动到备份目录
git ls-files -z | xargs -0 -I{} mv {} /tmp/backup/
```
这样可以先保留文件，确认无误后再删除备份。

## 核心功能演示

我们把这个脚本拆成几个核心步骤，这样更容易理解它的工作流程：

### 第一步：检查并记录远程地址
脚本会首先检查当前 Git 仓库是否配置了远程地址（如 `origin`）。这一步是用来预防误操作的，因为处理一个没有远程地址的本地仓库风险更高。

- **有远程地址**：将地址写入 `remote.txt` 文件。如果文件已存在，会自动添加一个毫秒级的时间戳后缀（例如 `remote_1703123456789.txt`）[reference:0]。
- **没有远程地址**：脚本会直接退出，并提示你这不是一个有效的 Git 仓库。

### 第二步：检查未提交修改
这是最后一道安全防线。在执行任何删除操作前，脚本会检查工作区是否有未提交的修改或未跟踪的文件[reference:1]。

- **检查方法**：使用 `git status --porcelain` 命令。这个命令的输出格式专门为脚本设计，非常稳定。如果输出不为空，说明有未提交的修改。
- **发现修改**：脚本会立即终止，并列出所有被修改或新增的文件，提示你先提交或暂存这些更改。

### 第三步：删除 Git 跟踪的文件
在确认无未提交修改后，脚本开始执行核心的清理工作。

- **获取文件列表**：通过 `git ls-files` 命令获取所有被 Git 跟踪的文件路径[reference:2]。
- **执行删除**：使用 Node.js 的 `fs.unlinkSync` 方法，同步地逐一删除这些文件[reference:3]。删除过程中会有一个动态的进度条，让你清晰地看到删除的进度和每一个被处理的文件。

### 第四步：一键删除空目录
文件删除后，可能会留下许多空文件夹。脚本提供了一个 `--delete-dir` 参数，用来清理这些空目录。

- **工作原理**：参数被激活后，脚本会递归遍历项目目录，检查每个文件夹是否为空。
- **安全删除**：只删除那些不包含任何文件的空文件夹，不会对你的项目结构造成意外破坏。

## 💻 实战代码

下面是实现上述所有功能的完整代码。你可以将它保存为一个独立的 `.js` 或 `.tsx` 文件（例如 `clean-tracked.tsx`）。

```tsx
#!/usr/bin/env node
import React, { FC, useEffect, useState } from 'react';
import { render, Text, Box, useApp, useInput } from 'ink';
import Spinner from 'ink-spinner';
import fs from 'node:fs/promises';
import path from 'node:path';
import { execa } from 'execa';

// --- 辅助函数: 生成带时间戳的文件名 ---
const getTimestampedFileName = async (basePath: string): Promise<string> => {
  const baseDir = path.dirname(basePath);
  const ext = path.extname(basePath);
  const name = path.basename(basePath, ext);
  try {
    await fs.access(basePath);
    // 文件存在, 生成带毫秒时间戳的新文件名
    const timestamp = Date.now();
    return path.join(baseDir, `${name}_${timestamp}${ext}`);
  } catch {
    // 文件不存在, 返回原路径
    return basePath;
  }
};

// --- 辅助函数: 检查未提交修改 (干净则返回 true)---
const isGitClean = async (cwd: string): Promise<boolean> => {
  try {
    const { stdout } = await execa('git', ['status', '--porcelain'], { cwd });
    return stdout.trim() === '';
  } catch (error) {
    throw new Error(`Git status 失败: ${error instanceof Error ? error.message : String(error)}`);
  }
};

// --- 辅助函数: 获取被跟踪的文件列表---
const getTrackedFiles = async (cwd: string): Promise<string[]> => {
  try {
    const { stdout } = await execa('git', ['ls-files'], { cwd });
    return stdout.split('\n').filter(Boolean);
  } catch (error) {
    throw new Error(`git ls-files 失败: ${error instanceof Error ? error.message : String(error)}`);
  }
};

// --- 辅助函数: 递归删除空目录---
const deleteEmptyDirs = async (dir: string): Promise<number> => {
  let deletedCount = 0;
  const entries = await fs.readdir(dir, { withFileTypes: true });
  for (const entry of entries) {
    const fullPath = path.join(dir, entry.name);
    if (entry.isDirectory() && !fullPath.includes('.git')) {
      deletedCount += await deleteEmptyDirs(fullPath);
    }
  }
  try {
    await fs.rmdir(dir);
    deletedCount++;
  } catch {
    // 目录非空, 跳过
  }
  return deletedCount;
};

// ==================== 主应用组件 ====================
const App: FC<{ deleteDir: boolean }> = ({ deleteDir }) => {
  const [step, setStep] = useState<'remote' | 'clean' | 'delete' | 'done'>('remote');
  const [error, setError] = useState<string | null>(null);
  const [remoteUrl, setRemoteUrl] = useState<string | null>(null);
  const [trackedFiles, setTrackedFiles] = useState<string[]>([]);
  const [deletedCount, setDeletedCount] = useState(0);
  const [emptyDirCount, setEmptyDirCount] = useState(0);
  const { exit } = useApp();

  useEffect(() => {
    const main = async () => {
      const cwd = process.cwd();
      try {
        // --- 1. 获取远程地址并写入文件---
        let url: string;
        try {
          const { stdout } = await execa('git', ['remote', 'get-url', 'origin'], { cwd });
          url = stdout.trim();
        } catch {
          setError('此仓库没有配置远程地址 (origin), 脚本终止。');
          return;
        }
        setRemoteUrl(url);
        const remoteFilePath = await getTimestampedFileName(path.join(cwd, 'remote.txt'));
        await fs.writeFile(remoteFilePath, url, 'utf-8');
        setStep('clean');

        // --- 2. 检查未提交修改---
        const isClean = await isGitClean(cwd);
        if (!isClean) {
          setError('当前有未提交的修改, 请先提交或暂存更改后再运行。');
          return;
        }
        setStep('delete');

        // --- 3. 删除被跟踪的文件---
        const files = await getTrackedFiles(cwd);
        setTrackedFiles(files);
        for (let i = 0; i < files.length; i++) {
          const filePath = path.join(cwd, files[i]);
          await fs.unlink(filePath).catch(() => {});
          setDeletedCount(i + 1);
        }
        
        // --- 4. 可选: 删除空目录---
        if (deleteDir) {
          const dirsDeleted = await deleteEmptyDirs(cwd);
          setEmptyDirCount(dirsDeleted);
        }
        setStep('done');
      } catch (err) {
        setError(err instanceof Error ? err.message : String(err));
      }
    };
    main();
  }, [deleteDir, exit]);

  useInput((input, key) => {
    if (key.escape || input === 'q') {
      exit();
    }
  });

  if (error) {
    return (
      <Box flexDirection="column">
        <Text color="red">❌ 错误: {error}</Text>
        <Text dimColor>按 Esc 或 q 退出</Text>
      </Box>
    );
  }

  if (step === 'remote') {
    return (
      <Box>
        <Text color="green">
          <Spinner type="dots" /> 正在检查远程仓库地址...
        </Text>
      </Box>
    );
  }

  if (step === 'clean') {
    return (
      <Box>
        <Text color="green">
          <Spinner type="dots" /> 正在检查未提交的修改...
        </Text>
      </Box>
    );
  }

  if (step === 'delete') {
    return (
      <Box flexDirection="column">
        <Text>
          正在删除被跟踪的文件: {deletedCount} / {trackedFiles.length}
        </Text>
        {trackedFiles.length > 0 && (
          <Text dimColor>当前文件: {trackedFiles[deletedCount - 1] || ''}</Text>
        )}
      </Box>
    );
  }

  return (
    <Box flexDirection="column" marginTop={1}>
      <Text color="green">✅ 任务已完成!</Text>
      <Text>远程地址已保存到 remote.txt (如有冲突已自动加时间戳)</Text>
      <Text>已删除被跟踪的文件数量: {deletedCount}</Text>
      {deleteDir && <Text>已删除的空目录数量: {emptyDirCount}</Text>}
      <Text dimColor>按任意键退出</Text>
    </Box>
  );
};

// ==================== 启动入口 ====================
const isDeleteDirEnabled = process.argv.includes('--delete-dir');
render(<App deleteDir={isDeleteDirEnabled} />);
```

```tsx
#!/usr/bin/env node
import React, { FC, useEffect, useState } from 'react';
import { render, Text, Box, useApp, useInput } from 'ink';
import Spinner from 'ink-spinner';
import TextInput from 'ink-text-input';
import Table from 'ink-table';
import { execa } from 'execa';
import fs from 'node:fs/promises';
import path from 'node:path';

// --- 解析命令行参数 ---
function parseArgs(): { cliPath: string | null; useCurrent: boolean; includeIgnored: boolean; output?: string } {
  const args = process.argv.slice(2);
  let cliPath: string | null = null;
  let useCurrent = false;
  let includeIgnored = false;
  let output: string | undefined;
  for (let i = 0; i < args.length; i++) {
    if (args[i] === '--path' || args[i] === '-p') {
      if (i + 1 < args.length) {
        cliPath = path.resolve(args[i + 1]);
        i++;
      }
    } else if (args[i] === '--current-path') {
      useCurrent = true;
    } else if (args[i] === '--include-ignored') {
      includeIgnored = true;
    } else if (args[i] === '--output' && i + 1 < args.length) {
      output = args[i + 1];
      i++;
    }
  }
  return { cliPath, useCurrent, includeIgnored, output };
}

// --- 获取未跟踪的文件列表 ---
async function getUntrackedFiles(cwd: string, includeIgnored: boolean): Promise<string[]> {
  try {
    const args = ['ls-files', '--others', '--exclude-standard'];
    if (includeIgnored) {
      // 如果想列出被忽略的文件，需要额外加 --ignored，但同时要排除标准排除规则？
      // 更准确: git ls-files --others --ignored --exclude-standard 会列出未跟踪和被忽略的文件
      args.push('--ignored');
    }
    const { stdout } = await execa('git', args, { cwd });
    return stdout.split('\n').filter(Boolean);
  } catch (error) {
    throw new Error(`git ls-files 失败: ${error instanceof Error ? error.message : String(error)}`);
  }
}

// --- 获取文件元信息（大小、修改时间）---
async function getFileInfo(filePath: string): Promise<{ size: string; mtime: string }> {
  try {
    const stat = await fs.stat(filePath);
    const size = stat.size < 1024 ? `${stat.size} B` : `${(stat.size / 1024).toFixed(1)} KB`;
    const mtime = stat.mtime.toLocaleString();
    return { size, mtime };
  } catch {
    return { size: '?', mtime: '?' };
  }
}

// --- 路径输入组件 ---
const PathInput: FC<{ onSubmit: (dir: string) => void }> = ({ onSubmit }) => {
  const [input, setInput] = useState('');
  useInput((_, key) => {
    if (key.escape) process.exit(0);
  });
  return (
    <Box flexDirection="column">
      <Text>请输入 Git 仓库路径：</Text>
      <TextInput value={input} onChange={setInput} onSubmit={(v) => onSubmit(path.resolve(v.trim()))} />
      <Text dimColor>按 Esc 退出</Text>
    </Box>
  );
};

// --- 主列表展示组件 ---
const Lister: FC<{ targetDir: string; includeIgnored: boolean; output?: string }> = ({
  targetDir,
  includeIgnored,
  output,
}) => {
  const [loading, setLoading] = useState(true);
  const [files, setFiles] = useState<{ path: string; size: string; mtime: string }[]>([]);
  const [error, setError] = useState<string | null>(null);
  const { exit } = useApp();

  useEffect(() => {
    const main = async () => {
      try {
        // 检查是否是 Git 仓库
        await execa('git', ['rev-parse', '--git-dir'], { cwd: targetDir });
        const rawFiles = await getUntrackedFiles(targetDir, includeIgnored);
        const withInfo = await Promise.all(
          rawFiles.map(async (f) => {
            const fullPath = path.join(targetDir, f);
            const { size, mtime } = await getFileInfo(fullPath);
            return { path: f, size, mtime };
          })
        );
        setFiles(withInfo);
        if (output) {
          const content = withInfo.map((f) => f.path).join('\n');
          await fs.writeFile(output, content, 'utf-8');
        }
      } catch (err) {
        setError(err instanceof Error ? err.message : String(err));
      } finally {
        setLoading(false);
      }
    };
    main();
  }, [targetDir, includeIgnored, output]);

  useInput((input, key) => {
    if (key.escape || input === 'q') exit();
  });

  if (error) {
    return (
      <Box flexDirection="column">
        <Text color="red">❌ {error}</Text>
        <Text dimColor>按 Esc 或 q 退出</Text>
      </Box>
    );
  }

  if (loading) {
    return (
      <Box>
        <Text color="green">
          <Spinner type="dots" /> 正在扫描未跟踪的文件...
        </Text>
      </Box>
    );
  }

  if (files.length === 0) {
    return (
      <Box flexDirection="column">
        <Text color="green">✅ 没有发现任何未跟踪的文件。</Text>
        <Text dimColor>按 Esc 或 q 退出</Text>
      </Box>
    );
  }

  const tableData = files.map((f, idx) => ({
    '#': idx + 1,
    文件路径: f.path,
    大小: f.size,
    修改时间: f.mtime,
  }));

  return (
    <Box flexDirection="column">
      <Text bold>
        发现 {files.length} 个未跟踪的文件{includeIgnored ? '（包含被忽略的文件）' : ''}：
      </Text>
      <Box marginY={1}>
        <Table data={tableData} />
      </Box>
      {output && (
        <Text color="cyan">
          已导出文件列表到：{output}
        </Text>
      )}
      <Text dimColor>按 Esc 或 q 退出</Text>
    </Box>
  );
};

// --- 主应用 ---
const App: FC = () => {
  const { cliPath, useCurrent, includeIgnored, output } = parseArgs();
  const [targetDir, setTargetDir] = useState<string | null>(() => {
    if (cliPath) return cliPath;
    if (useCurrent) return process.cwd();
    return null;
  });

  if (!targetDir) {
    return <PathInput onSubmit={(dir) => setTargetDir(dir)} />;
  }

  return <Lister targetDir={targetDir} includeIgnored={includeIgnored} output={output} />;
};

render(<App />);
```

```tsx
import React, { FC, useEffect, useState } from 'react';
import { render, Text, Box, useApp, useInput } from 'ink';
import Spinner from 'ink-spinner';
import TextInput from 'ink-text-input';
import { execa } from 'execa';
import fs from 'node:fs/promises';
import path from 'node:path';

// --- 解析参数 ---
function parseArgs(): { rootPath: string | null; useCurrent: boolean; includeIgnored: boolean; output?: string } {
  const args = process.argv.slice(2);
  let rootPath: string | null = null;
  let useCurrent = false;
  let includeIgnored = false;
  let output: string | undefined;
  for (let i = 0; i < args.length; i++) {
    if (args[i] === '--path' || args[i] === '-p') {
      if (i + 1 < args.length) {
        rootPath = path.resolve(args[i + 1]);
        i++;
      }
    } else if (args[i] === '--current-path') {
      useCurrent = true;
    } else if (args[i] === '--include-ignored') {
      includeIgnored = true;
    } else if (args[i] === '--output' && i + 1 < args.length) {
      output = args[i + 1];
      i++;
    }
  }
  return { rootPath, useCurrent, includeIgnored, output };
}

// --- 递归查找所有 Git 仓库（包含 .git 目录的文件夹）---
async function findGitRepos(root: string): Promise<string[]> {
  const repos: string[] = [];
  async function walk(dir: string) {
    let entries;
    try {
      entries = await fs.readdir(dir, { withFileTypes: true });
    } catch {
      return; // 无权限或不可读则跳过
    }
    // 检查当前目录是否是 Git 仓库（有 .git 子目录）
    const hasGit = entries.some(entry => entry.isDirectory() && entry.name === '.git');
    if (hasGit) {
      repos.push(dir);
      return; // 不再进入子目录，因为内部 .git 已算作一个仓库，子目录可能不是独立仓库
    }
    // 否则继续递归子目录
    for (const entry of entries) {
      if (entry.isDirectory() && entry.name !== '.git') {
        await walk(path.join(dir, entry.name));
      }
    }
  }
  await walk(root);
  return repos;
}

// --- 获取某个仓库中未跟踪的文件列表 ---
async function getUntrackedFiles(repoDir: string, includeIgnored: boolean): Promise<string[]> {
  try {
    const args = ['ls-files', '--others', '--exclude-standard'];
    if (includeIgnored) {
      args.push('--ignored');
    }
    const { stdout } = await execa('git', args, { cwd: repoDir });
    return stdout.split('\n').filter(Boolean);
  } catch (error) {
    // 如果 git 命令失败，返回空数组并记录警告（比如仓库损坏）
    console.error(`警告: 无法读取仓库 ${repoDir}: ${error instanceof Error ? error.message : String(error)}`);
    return [];
  }
}

// --- 交互式路径输入 ---
const PathInput: FC<{ onSubmit: (dir: string) => void }> = ({ onSubmit }) => {
  const [input, setInput] = useState('');
  useInput((_, key) => {
    if (key.escape) process.exit(0);
  });
  return (
    <Box flexDirection="column">
      <Text>请输入顶层目录路径（会递归查找其下所有 Git 仓库）：</Text>
      <TextInput value={input} onChange={setInput} onSubmit={(v) => onSubmit(path.resolve(v.trim()))} />
      <Text dimColor>按 Esc 退出</Text>
    </Box>
  );
};

// --- 扫描结果展示组件 ---
const Scanner: FC<{ rootDir: string; includeIgnored: boolean; output?: string }> = ({ rootDir, includeIgnored, output }) => {
  const [loading, setLoading] = useState(true);
  const [repos, setRepos] = useState<{ dir: string; files: string[] }[]>([]);
  const [error, setError] = useState<string | null>(null);
  const { exit } = useApp();

  useEffect(() => {
    const main = async () => {
      try {
        // 1. 查找所有 Git 仓库
        const repoDirs = await findGitRepos(rootDir);
        if (repoDirs.length === 0) {
          setError(`未在 ${rootDir} 下找到任何 Git 仓库。`);
          setLoading(false);
          return;
        }
        // 2. 并发获取每个仓库的未跟踪文件（限制并发数避免过载）
        const concurrency = 10;
        const results: { dir: string; files: string[] }[] = [];
        for (let i = 0; i < repoDirs.length; i += concurrency) {
          const batch = repoDirs.slice(i, i + concurrency);
          const batchResults = await Promise.all(
            batch.map(async (dir) => ({
              dir,
              files: await getUntrackedFiles(dir, includeIgnored),
            }))
          );
          results.push(...batchResults);
        }
        setRepos(results);
        // 3. 可选导出
        if (output) {
          const lines: string[] = [];
          for (const repo of results) {
            lines.push(`\n[${repo.dir}]`);
            if (repo.files.length === 0) {
              lines.push('  (无未跟踪文件)');
            } else {
              repo.files.forEach(f => lines.push(`  ${f}`));
            }
          }
          await fs.writeFile(output, lines.join('\n'), 'utf-8');
        }
      } catch (err) {
        setError(err instanceof Error ? err.message : String(err));
      } finally {
        setLoading(false);
      }
    };
    main();
  }, [rootDir, includeIgnored, output]);

  useInput((input, key) => {
    if (key.escape || input === 'q') exit();
  });

  if (error) {
    return (
      <Box flexDirection="column">
        <Text color="red">❌ {error}</Text>
        <Text dimColor>按 Esc 或 q 退出</Text>
      </Box>
    );
  }

  if (loading) {
    return (
      <Box>
        <Text color="green">
          <Spinner type="dots" /> 正在递归扫描 Git 仓库并收集未跟踪文件...
        </Text>
      </Box>
    );
  }

  const totalUntracked = repos.reduce((sum, r) => sum + r.files.length, 0);
  const reposWithUntracked = repos.filter(r => r.files.length > 0);

  return (
    <Box flexDirection="column">
      <Text bold>📁 扫描根目录: {rootDir}</Text>
      <Text>发现 {repos.length} 个 Git 仓库，其中 {reposWithUntracked.length} 个含有未跟踪文件（总计 {totalUntracked} 个文件）。</Text>
      <Box marginY={1}>
        {reposWithUntracked.length === 0 ? (
          <Text color="green">✅ 所有仓库工作区都很干净！</Text>
        ) : (
          reposWithUntracked.map((repo, idx) => (
            <Box key={idx} flexDirection="column" marginBottom={1}>
              <Text color="cyan" bold>📂 {repo.dir}</Text>
              <Text>未跟踪文件数: {repo.files.length}</Text>
              {repo.files.slice(0, 10).map((file, i) => (
                <Text key={i} dimColor>  - {file}</Text>
              ))}
              {repo.files.length > 10 && <Text dimColor>  ... 还有 {repo.files.length - 10} 个文件未显示</Text>}
            </Box>
          ))
        )}
      </Box>
      {output && <Text color="green">✅ 结果已导出到 {output}</Text>}
      <Text dimColor>按 Esc 或 q 退出</Text>
    </Box>
  );
};

// --- 主应用 ---
const App: FC = () => {
  const { rootPath, useCurrent, includeIgnored, output } = parseArgs();
  const [targetDir, setTargetDir] = useState<string | null>(() => {
    if (rootPath) return rootPath;
    if (useCurrent) return process.cwd();
    return null;
  });

  if (!targetDir) {
    return <PathInput onSubmit={(dir) => setTargetDir(dir)} />;
  }

  return <Scanner rootDir={targetDir} includeIgnored={includeIgnored} output={output} />;
};

render(<App />);
```

```ts
async function getSubmodulePaths(repoDir: string): Promise<string[]> {
  try {
    const { stdout } = await execa('git', ['submodule', 'status', '--recursive'], { cwd: repoDir });
    // 输出格式: " 160000 abc123... path/to/submodule (v1.0)"
    const paths: string[] = [];
    for (const line of stdout.split('\n')) {
      const match = line.match(/^[+\- ]?[a-f0-9]{40,}\s+(\S+)/);
      if (match) {
        paths.push(match[1]);
      }
    }
    return paths;
  } catch {
    return []; // 没有子模块或命令失败
  }
}
```

### 2. 获取一个仓库（包括其子模块）的所有未跟踪文件

```ts
async function getAllUntrackedFiles(repoDir: string, includeIgnored: boolean): Promise<{ repo: string; files: string[] }[]> {
  const results: { repo: string; files: string[] }[] = [];
  // 主仓库自身
  const mainFiles = await getUntrackedFiles(repoDir, includeIgnored);
  results.push({ repo: repoDir, files: mainFiles });
  
  // 子模块
  const submodules = await getSubmodulePaths(repoDir);
  for (const sub of submodules) {
    const subPath = path.join(repoDir, sub);
    const subFiles = await getUntrackedFiles(subPath, includeIgnored);
    results.push({ repo: subPath, files: subFiles });
  }
  return results;
}
```

### 一、通用特性（所有子命令共享）

| 特性编号 | 需求描述 |
|---------|----------|
| G1 | 支持通过命令行参数指定目标路径：`--path <dir>` 或 `-p`；若提供 `--current-path` 则使用当前工作目录。 |
| G2 | 若未提供任何路径参数，则进入交互模式，使用 Ink 的 `TextInput` 让用户输入路径。 |
| G3 | 支持非交互模式：`--non-interactive` 或 `-n`。在此模式下，必须提供完整参数（如 `--path`），不启动任何交互输入，不等待按键，完成后自动退出。适合 Agent 调用。 |
| G4 | 所有子命令均提供 `--help` 或 `-h` 显示帮助信息。 |

### 二、子命令 `delete`：删除 Git 仓库中所有被跟踪的文件

| 特性编号 | 需求描述 |
|---------|----------|
| D1 | 检查当前仓库是否有远程地址（`origin`）。若无，则报错退出。 |
| D2 | 将远程地址写入当前仓库根目录下的 `remote.txt` 文件。若该文件已存在，则自动添加毫秒时间戳后缀（如 `remote_1703123456789.txt`）。 |
| D3 | 检查是否有未提交的修改（包括暂存区和工作区）。若有，则报错退出并提示用户先提交或暂存。 |
| D4 | 使用 `git ls-files` 获取所有被 Git 跟踪的文件列表，然后逐一删除（`fs.unlink`）。 |
| D5 | 提供可选参数 `--delete-dir`：在删除文件后，递归删除项目中的所有空目录（但保留 `.git` 目录）。 |
| D6 | 删除过程中显示实时进度（交互模式下用进度条；非交互模式下输出简单日志）。 |
| D7 | 完成时显示已删除的文件数量；若启用 `--delete-dir`，还显示已删除的空目录数量。 |

### 三、子命令 `list`：列出指定 Git 仓库中未被跟踪的文件（单仓库）

| 特性编号 | 需求描述 |
|---------|----------|
| L1 | 在目标 Git 仓库中执行 `git ls-files --others --exclude-standard`，获取未被跟踪的文件列表（不包含 `.gitignore` 中忽略的文件）。 |
| L2 | 提供可选参数 `--include-ignored`：同时列出被 Git 忽略的文件（添加 `--ignored` 标志）。 |
| L3 | 可选显示每个文件的元信息：文件大小、修改时间（使用表格展示）。可通过 `--verbose` 或 `--show-meta` 启用。 |
| L4 | 提供可选参数 `--output <file>`：将文件列表（每行一个路径）导出到指定文本文件。 |
| L5 | 交互模式下，若未指定 `--output`，则在终端以表格形式展示结果（最多显示前 100 条，超出时提示）。 |
| L6 | 非交互模式下，默认将结果输出到 stdout（每行一个路径），除非指定 `--output`。 |
| L7 | 只读操作，绝不修改任何文件。 |

### 四、子命令 `scan`：递归扫描顶层目录下的所有 Git 仓库（含子模块），汇总未跟踪文件

| 特性编号 | 需求描述 |
|---------|----------|
| S1 | 接受一个顶层目录（通过 `--path` 或交互输入），递归寻找其中所有包含 `.git` 子目录的 Git 仓库。 |
| S2 | **避免全量文件系统递归**：对于每个找到的仓库，通过 `git submodule status --recursive` 获取其所有子模块路径，以此覆盖嵌套仓库（子模块）。不扫描非子模块类型的嵌套仓库（即手动 `git init` 的野生嵌套仓库忽略）。 |
| S3 | 对每个独立的仓库（包括主仓库和子模块）执行 `git ls-files --others --exclude-standard`，获取其未跟踪文件列表。支持 `--include-ignored` 选项（同 L2）。 |
| S4 | 去重：同一个仓库不会被重复扫描（例如既作为顶层仓库又被父仓库的子模块引用）。 |
| S5 | 输出汇总报告：显示每个仓库的路径、未跟踪文件数量。交互模式下，每个仓库最多列出前 10 个文件路径；非交互模式下可列出全部（或由 `--full` 控制）。 |
| S6 | 提供可选参数 `--output <file>`：将完整报告（包含所有文件路径）导出到文本文件。 |
| S7 | 交互模式下使用进度条显示扫描进度（如“已扫描 X 个仓库”）。 |
| S8 | 非交互模式下，输出格式默认简洁（可增加 `--json` 选项输出结构化数据）。 |

### 五、参数使用示例（非交互模式）

```bash
# 删除模式：指定目录，启用空目录删除
git-helper delete --path /my/repo --delete-dir --non-interactive

# 列出模式：指定目录，包含忽略文件，导出结果
git-helper list --path /my/repo --include-ignored --output list.txt --non-interactive

# 扫描模式：递归扫描 /workspace，包含忽略文件，输出 JSON
git-helper scan --path /workspace --include-ignored --json --non-interactive
```
